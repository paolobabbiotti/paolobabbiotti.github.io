# CV website

- Modifica `cv.md`: è l’unica fonte del contenuto del sito.
- Anteprima locale facoltativa: installa Jekyll, poi esegui `jekyll serve` e apri `http://localhost:4000`.
- Pubblicazione: su GitHub, in **Settings → Pages**, scegli **Deploy from a branch**, quindi il branch `main` e la cartella `/ (root)`. Ogni push successivo aggiornerà il sito.
